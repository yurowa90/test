## 실제 반영

- `design-references.ts`: 7개 출처 등록, 15개 개선 사례, 주제·단계별 안내 선택, 출처 쪽수, 교사 확인 질문. 기출 구조 분석은 앱의 해석임을 표시한다.
- `ReferenceCoach.tsx`: 기존 4단계에 ‘자료에서 배우는 문항 개선’ 추가. 문제점 → 개선 방법 → 이유 → 교사 질문과 PDF 근거를 펼쳐 볼 수 있다. 전체 출처와 분석 범위도 제공한다.
- 분석·자료/명제 생성·최종 검토 프롬프트에 화면과 같은 설계 관점을 전달한다. 별도 필수 동의나 단계 이동 조건은 추가하지 않는다.
- 교사용 내보내기에 출제 학습 참고자료를 추가한다. 학생용의 실제 자료 출처와 분리한다.
- 지구과학 지식의 ‘이후 사례 미확보’ 한계를 수정하고, 15건의 수정 관점을 요약한다.
- 실제 데이터 단순화 시 수치·단위·표본 조건을 임의 변경하지 않도록 명시한다. 반올림·정규화·생략 기록은 앱이 추가한 무결성 장치이지 원문의 직접 인용이 아니다.
- 성취수준 A~E와 목표 난도 상·중·하의 기계적 대응을 제거한다. 주 평가 요소와 연결되는 보조 추론은 허용한다.

## 적용 한계

과거 교육과정과 당시 전국연합학력평가의 맥락이 섞여 있다. 역사적 과목별 범위·교과서 수록 비율·예상 정답률을 현재 모든 수업 평가에 적용할 의무 기준으로 취급하지 않는다. 현재 선택한 성취기준과 실제 수업 범위를 우선한다.

첨부 PDF 전체, 원본 그림, 문항·정답 묶음은 공개 저장소나 배포물에 추가하지 않았다. 새 데이터는 설계 원리와 문항 구조에 대한 요약이며, 연구의 실측값 데이터베이스가 아니다. 논문·전공서적의 실제 그래프·표를 사용하려면 기존 출처 입력에서 원문 위치·조건·수치를 별도로 대조해야 한다. 모델 학습이나 원문 자동 검색 기능을 추가한 것은 아니다.

수록 해설이나 정답 표시를 독립적인 과학 검증 결과로 사용하지 않았다. 새 안내가 실제 생성물의 품질을 보장하는 것은 아니므로, 교사 검토와 실제 학생 반응에 따른 수정 기록을 유지한다.
