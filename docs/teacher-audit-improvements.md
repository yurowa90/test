# 교사 관점 검토 후 개선 (2026-09-08)

이 기록은 실제 교사 20명의 사용자 시험이 아니라, 가상 교사 관점 점검에서 발견한 문제의 수정 기록이다.

- 원자료의 숫자 존재 검사에 표 행·열과 그래프 범주·계열 대응 검사를 추가했다. 새 숫자와 동일 항목의 변경된 값을 차단한다. 자동 대조가 불가능한 자연어·단위·조건은 교사가 근거를 기록해 대조한다. 과학적 의미의 완전한 자동 검증은 아니다.
- 출처 위치 수정은 읽기 결과를 지우지 않는다. 원문 교체·재생성·요청 변경 시 이전 원문과 수정안을 최대 20개 보관하고 복원한다. 첨부 원본은 옆에서 열람할 수 있으며 파일 자체는 영구 저장하지 않는다.
- 교사가 먼저 문제를 진단하고 수정안의 채택·보류와 근거를 기록한다. AI 제안 이유는 교사의 성찰과 구분한다. 성장 노트에는 수업 적용과 학생 반응 기록을 추가했다.
- 가져온 문항의 개별 명제 수준·행동 영역과 자료 복잡도는 미분류로 표시한다. 직접 분류해야 다음 단계로 진행한다.
- 예시 합성 문항은 키 없이 4단계까지 진행한다. 선택한 진술 순서와 교사 수정 내용을 사용하고 AI 검토 미실행을 명시한다. 일반 생성은 선택한 Gemini 모델과 검증된 키를 사용한다.
- 생성 요청 취소, 작업 방식 유지, 모바일 조립 요약, 분석 입력 접근성 이름을 추가했다.
- JSON 백업 복원은 구조와 필수값을 검사하고 현재 작업을 보관한다. 가져온 최종 결과·승인은 버리고 명제와 출처를 재검토한다. 키는 백업에 포함하지 않는다.
- 그림 제작 지시만 있고 실제 그림이 없거나 미해결 AI 점검에 교사 판단 근거가 없으면 최종 내보내기를 제한한다.

검증: 회귀 테스트 76개와 TypeScript·Vite 프로덕션 빌드. 실제 Gemini 계정의 키·할당량 및 과학적 생성 품질은 이번 검증에 포함하지 않는다. 그림 지원은 막대·꺾은선·과정 모식도로 제한된다.

실행 위치: mcq-builder. 기존 저장소 루트의 논술형 앱 소스와 별개이다.

## 후속 수정 (2026-09-08)

- 원자료 본문과 조건을 동일한 검증 경로로 결합했다. 조건에만 기록된 수치로 만든 그래프가 제거되거나 가져오기에서 차단되던 오류를 수정했다. 원문에 없는 수치의 차단은 유지한다.
- 꺾은선그래프의 수치형 x축은 `0.0`과 `0`, `1e0`과 `1`처럼 같은 수치를 동일하게 대조한다. 단위가 붙은 셀, 범위, 복수 수치, 중복 행은 자동 일치로 승인하지 않는다. 막대그래프의 범주 이름은 문자열로 구분한다.
- 기존 문항 개선에서 과목·성취기준을 바꾸면 이전 공식 성취기준 선택기 상태도 초기화하여 직접 입력 내용과 화면 표시가 일치하도록 했다.
- 사용 안내의 JSON 복원·실제 SVG 그림 출력 지원 여부를 현재 구현에 맞췄다.

추가 회귀 테스트 5개를 포함한 전체 81개 테스트와 TypeScript·Vite 빌드를 통과했다. 실제 Gemini 키를 사용한 유료 생성·첨부 판독 품질 평가는 포함하지 않는다.
