# 문항 그림 지원

## 사용 흐름

- 새 자료 생성 시 막대·꺾은선·과정 모식도의 구조화된 그림 데이터를 함께 요청한다.
- 기존 문항은 3단계 또는 4단계의 ‘이 자료로 그림 만들기’로 그림만 추가할 수 있다. 현재 선택한 Gemini 모델과 API 키를 사용하며, 별도 이미지 모델은 필요하지 않다.
- API 없이 3단계 ‘그림 직접 작성·수정’에서 표 값을 붙여넣거나 과정별 설명을 입력할 수 있다.
- 그림 적용은 자료 변경이므로 선택한 명제의 확인·연습 판정·최종 승인을 해제한다. 기존 본문과 명제는 보존한다. 4단계에서 그림을 추가하면 3단계에서 재검토한다.
- 본문·간접 발문·조건·그림 제작 지시·출처 연결 변경 시 이전 그림을 해제한다. 버전 보관과 작업 백업에는 그림 데이터도 포함한다.

## 표현 범위

막대그래프는 범주 2~10개, 계열 1~4개를 지원한다. 꺾은선은 수치 x축만 지원하며 실제 간격을 보존한다. 과정 모식도는 2~6단계의 상태와 설명을 표시한다. 그림은 흑백이며 수치 그래프의 범위에는 0을 포함한다. 음수·0만 있는 자료도 표시한다.

정밀한 해부도·회로도·지도·다중 패널·로그 축·오차 막대는 현재 지원하지 않는다. AI가 해당 유형을 대신할 수 없다고 응답하면 기존 작업을 유지하고 이유를 표시한다.

예를 들어 ‘살충제 살포 후 A는 감소하고 B의 비율은 증가했다’에 구체적인 비율이 없다면 임의의 90:10, 20:80 막대를 만들지 않는다. 관찰된 상태를 과정 모식도로 표시한다. 모식도의 상자 크기나 개수는 개체 수를 뜻하지 않는다. 학생이 판단해야 할 자연선택의 원리나 명제 정답을 그림 설명에 추가하지 않도록 지시한다.

## 데이터와 출력

AI가 SVG·HTML 코드를 생성하지 않는다. 제한된 데이터 구조를 검증한 뒤 앱이 SVG를 그린다. 텍스트는 XML 이스케이프하며 외부 리소스와 스크립트는 삽입하지 않는다. 그래프 값이 제공된 자료의 수치 목록에 있는지도 검사한다. 출처 기반 모드는 교사가 확인하고 연결한 원자료 발췌를 사용한다. 이 검사는 단위·시점·대상 대응의 과학적 검증을 대신하지 않으며, 교사에게 그림의 값과 근거를 대조하도록 안내한다.

SVG와 PNG를 별도 저장할 수 있다. 학생용 HTML은 SVG와 자료 표를 포함한 독립 문서로, 브라우저에서 인쇄/PDF 저장할 수 있다. Markdown은 그림을 데이터 URL로 포함하지만 일부 Markdown 뷰어가 이를 표시하지 않을 수 있으므로 그림 포함 문서에는 HTML을 권장한다. 교사용 그림 근거·정답·해설·제작 지시는 학생용 HTML/SVG에 넣지 않는다.

Gemini 실호출 결과는 사용자의 모델·할당량과 자료 내용에 따라 달라질 수 있다. 자동화 테스트는 수치 좌표, 누락 데이터, 텍스트 이스케이프, 학생용 출력 분리, 상태 무효화 및 저장 복원을 검증한다.
