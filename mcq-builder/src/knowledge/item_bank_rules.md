# 〈보기〉 명제 풀(아이템뱅크)과 조립 규칙

**근거**: (1) 경기도교육청 (2024) 『2024 평가문항 제작 방법』 Ⅱ장 발문·〈보기〉·선택지 작성 원리(p.24, p.42–51). (2) 사용자 스킬 sci-mcq-builder `references/writing-rules.md`, `references/item-bank-mode.md`, `scripts/hapdab_check.py`, `scripts/difficulty.py`(교육청 출제 연수 원리를 결정론적 규칙으로 코드화한 것).

## 1. 명제 풀의 구조
- **자료(stimulus) 1개**: 간접 발문 + 자료 본문(표·실험 과정·제시문·대화, 그림·그래프는 상세 묘사와 제작 지시) + 단서 조항 + 직접 발문의 앞부분('이에 대한 설명으로').
- **참 명제 후보**와 **매력적 오답(거짓) 명제 후보**를 같은 자료에서 균형 있게 뽑는다. 산출물은 그대로 쓰는 완성 문항이 아니라 **교사가 조합하는 원자재**다.
- 각 명제에는 **성취수준 라벨(A~E)**, **행동 영역**, **해설**(거짓이면 "왜 그렇게 오해하는가 + 올바른 개념")을 단다.

## 2. 명제 작성 규칙
- ㄱ, ㄴ, ㄷ 각 명제는 **독립적으로 참/거짓 판정**이 가능해야 한다. 하나를 알면 다른 하나가 자동으로 결정되는 명제 쌍은 금지(교육청 p.46).
- 거짓 명제는 **빈출 오개념**에 기반해 매력적으로 만든다. 무작정 틀린 진술 금지. 관점에 따라 참이 될 여지가 있는 거짓, 예외 상황에서 뒤집히는 참은 금지(정답 시비).
- 명제 길이·구문을 비슷하게 맞춰 **길이 단서**가 없게 한다. 병렬 구조('~는 ~이다.', '~는 A가 B보다 크다.')를 유지한다.
- 부정 표현(아니다, 없다)은 꼭 필요할 때만. 이중 부정 금지. '언제나, 항상, 반드시, 모두, ~만' 같은 단서 어휘 회피.
- 명제는 **자료에서 판단**되어야 한다. 자료 없이 단순 지식만 확인하는 명제는 지양하되, 이해 영역 명제 1~2개는 허용.
- **교과서 밖 지식 요구 금지**. 성취기준 범위 안에서. 시사·특정 상표·논쟁적 소재 금지.
- 비교 명제는 비교 대상과 방향을 명확히: "방출되는 빛의 파장은 A에서가 B에서보다 길다."(교육청 p.72).
- 교과 간 융합 문항(통합과학)이면 물리·화학·생명·지구 영역을 ㄱ, ㄴ, ㄷ에 분산할 수 있다.

## 3. 성취수준 라벨 = 판별점 기준
그 명제를 **옳게 판단하는 데 필요한 최소 성취수준**으로 라벨링한다.
- **A** = 최상위 수준 학생만 옳게 판단 가능(변별력 최대)
- **B / C / D** = 중상 / 중 / 중하
- **E** = 최하위 수준 학생도 옳게 판단 가능(가장 쉬움)
판단 근거: 요구되는 개념 연결 수, 자료 해석 깊이, 오개념 함정의 교묘함. 성취기준에 공식 성취수준 A~E 서술이 있으면 그 서술의 수행 동사·범위에 맞춰 라벨을 정한다. 풀 전체가 A~E에 고루 분포하도록 한다.

## 4. 조립(앱이 결정론적으로 수행)
- **발문 분기**: 선택지의 항목 개수가 모두 같으면 "옳은 것만을 〈보기〉에서 고른 것은?", 다르면 "옳은 것만을 〈보기〉에서 있는 대로 고른 것은?"(교육청 p.32).
- **표준 배열**: 3항 〈보기〉는 비균일 배열(예: ① ㄱ ② ㄴ ③ ㄱ, ㄷ ④ ㄴ, ㄷ ⑤ ㄱ, ㄴ, ㄷ), 4항 〈보기〉는 2개씩 균일 배열(예: ① ㄱ, ㄴ ② ㄱ, ㄷ ③ ㄴ, ㄷ ④ ㄴ, ㄹ ⑤ ㄷ, ㄹ). 항목 개수 유형은 세 가지 이내(p.47).
- **복수 정답 차단**: 균일 배열에서 정답 외 선택지가 참 명제만으로 구성되면 복수 정답. 4항 균일 배열은 참 명제가 정확히 2개일 때만 성립.
- **정답 위치**: ①에 몰지 않는다. 항목이 가장 많은 선택지만 정답으로 하지 않는다(p.50).
- 정답형은 참 1 + 거짓 4, 부정형은 참 4 + 거짓 1. 부정형 발문의 '않은'에 밑줄.

## 5. 난이도 7등급 추천 (difficulty.py 이식)
- 라벨 가중치 A=5, B=4, C=3, D=2, E=1 → 선택 명제의 평균이 기본 점수.
- 정답 구조 가중: 정답 명제 1개 0.0 / 2개 0.6 / 3개 0.3 (2개일 때 변별 최대).
- 맥락 가중: 자료 복잡도(0/1/2)×0.4 + 부정 발문×0.5 + 교과 융합×0.5.
- 종합 점수(약 1.0~6.5)를 7구간에 매핑: D, C, C+, B, B+, A, A+ (낮음→높음). **권장치이며 최종 판단은 교사**. 실제 응답 자료가 쌓이면 경계값 재보정.
