# 평가 문항 제작 절차

**출처**: 경기도교육청 (2024). 『2024 평가문항 제작 방법』 Ⅱ장 3절 「평가 문항 제작 절차」 p.52, Ⅲ장 「평가 문항 제작의 실제」 각 과목 '다. 평가 문항 제작 절차'(물리학 pp.68–72, 화학 pp.66–69, 생명과학 pp.68–72, 지구과학 pp.67–70).

## 절차 (p.52; 물리학편은 '필수 학습 요소 추출'을 넣어 7단계)
1. **교육과정 분석** — 영역별 학습 내용, 성취기준, 성취수준을 상세히 분석한다.
2. **필수 학습 요소 추출** — 평가 목표는 교육과정의 내용 요소로 검토한다. 교과서(검정)에 있는 활동이라도 교육과정 내용 요소와 무관할 수 있다(p.69).
3. **평가 요소 선정** — 학습 목표 성취에 요구되는 내용 요소·행동 요소를 파악해 평가 요소와 **평가 목표**를 정한다.
   - 유의점: 세목화한 학습 요소를 비교해 **하위 요소를 포섭하는 상위 요소**를 고른다. 교육과정에서 **중요하게 다뤄지는 요소**를 골라 내적 타당도를 높인다. 중요한 평가 요소는 같은 교육과정 안에서 문제 유형을 달리해 반복 출제되는 것이 일반적이다.
   - 산출 형식: `평가 요소: ○○의 개념과 ○○ 과정` / `평가 목표: ~을 알고 ~을 파악할 수 있는지 평가한다.`
4. **문제 장면 설정** — 평가 요소를 '살아 움직이게' 채색하는 단계. 평가 요소가 '몸'이면 문제 장면은 '옷'. 같은 평가 요소도 평가 목표·교과 특성·출제자의 평가관에 따라 다양한 장면으로 접근할 수 있지만, 장면이 비합리적이면 평가 효과가 반감된다(p.69).
   - 산출 형식: `문제 상황 설정: …` / `자료 제시: 〈그림/표/실험〉 … ◦ 무엇을 제시 ◦ 무엇을 한정`
5. **문항 초안 작성** — 교육과정과 일치하고 평가 요소가 분명히 드러나게. 문항 유형(정답형·최선답형·합답형)을 정하고 **발문·자료·답지가 유기적으로 연계**되게. 자료·발문의 단순화/복잡화, 요구되는 지식·기능·사고의 범위 조절로 난도를 만든다.
6. **문항 검토(컨설팅)** — 정답 시비, 제3자의 오해 소지, 학문적 오류, 자료 표기·표현을 검토. 동료 검토는 타당도·신뢰도 확보의 필수 과정.
7. **최종 문항 완성** — 검토 의견 중 반영할 것과 안 할 것을 정해 수정하고, 수정 사항 반영 여부·파일 혼동·그림·기호 누락을 재확인.

## 과목별 절차 예시 (Ⅲ장)
### 물리학Ⅰ (pp.68–72)
- 성취기준 [12물리Ⅰ02-02] 원자 내 전자의 불연속적 에너지 준위를 스펙트럼 관찰로 설명. 성취수준 상/중/하 제시.
- 평가 요소: 불연속적인 에너지 준위의 개념과 전이 과정에서 에너지의 흡수·방출. 평가 목표: 보어 수소 원자 모형에서 양자수에 따른 에너지 준위가 불연속적임을 알고 전이 과정을 파악할 수 있는지 평가.
- 문제 장면: 양자수에 따른 에너지 준위 그림 + 전이 A, B, C 표시 / 방출 에너지.
- 초안 → 컨설팅 의견: 에너지 준위 간격의 물리적 오류, 문두에 '빛 방출' 언급 없음, ㄱ의 비교 대상 불명확, ㄷ의 전이 출발 준위가 그림에 없음 → 최종본에서 발문에 조건을 보강하고 〈보기〉를 "방출되는 빛의 파장은 A에서가 B에서보다 길다."처럼 비교 대상을 명확히 함.

### 화학Ⅰ (pp.66–69)
- [12화학Ⅰ02-04] 주기율표가 만들어지기까지의 과정. 평가 요소: 주기율표 발달 과정 및 특징. 평가 목표: 주기율표를 제안한 과학자들의 사고 과정과 주기율표의 특징을 파악하는지 평가.
- 문제 장면: 멘델레예프·모즐리·현대 주기율표에 대해 대화하는 세 학생(말풍선).
- 컨설팅 의견: 주기율표 문항인데 주기율표를 제시하지 않고 단순 지식만 물음, '대화'라면서 각자 주장만 하는 연출, 온라인 메시지 등 자연스러운 상황 필요 → 최종본은 '원격 수업 장면'으로 수정.

### 생명과학Ⅱ (pp.68–72)
- [12생과Ⅱ01-02] 생명과학 발달에 기여한 연구 방법. 평가 요소: 생명과학의 연구 방법. 평가 목표: 세포 분획법의 특징을 알고 원리를 적용해 세포 소기관의 특징을 파악하는지 평가.
- 문제 장면: 동물 세포 소기관을 세포 분획법으로 분리하는 실험 과정과 결과(균질기 파쇄, 원심 분리 g값·시간, 상층액·침전물 구분).
- 컨설팅 의견: 전자 현미경 관찰이 이 문항의 평가 요소에 타당한가, 회전 속도가 교과서마다 달라 검증 필요, 소포체의 DNA 유무는 예외 상황까지 검증, "관찰하기에 적합하다"는 진위 판단이 모호 → 최종본은 상층액 ㉠·㉡을 정의하고 〈보기〉를 "ㄱ. A는 미토콘드리아이다. ㄴ. ㉠과 ㉡에 모두 소포체가 있다. ㄷ. 이 실험에서 세포 분획법이 이용되었다."로 재구성.

### 지구과학Ⅰ (pp.67–70)
- [12지과Ⅰ03-02] 태풍 통과 시 날씨 변화를 일기도·위성 영상으로 설명. 평가 요소: 태풍 통과 시 날씨 변화와 특징.
- 문제 장면: 2018년 태풍 솔릭의 이동 경로(일정 시간 간격) + 적외선 영상.
- 컨설팅 의견: 위성 영상에서 태풍이 한반도와 멀어 〈보기〉의 구름과 무관, 두 지도의 구역 불일치, 지역·시간 지칭 모호, 기호 가독성 → 최종본은 23일 15시·24일 15시 두 시점 영상으로 바꾸고 〈보기〉를 시점·지점이 특정되게 수정.

## 이 앱의 대응
- Pass 1(교육과정 분석·평가 요소 선정·문제 장면 설정)은 교사가 검토·확정하는 관문이다.
- Pass 2a(명제 풀)와 앱의 결정론적 조립(발문 분기·선택지 배열·복수 정답 차단)이 '문항 초안 작성'에 해당한다.
- Pass 2b(윤문·해설·문항정보표·검토 체크리스트 자기 대조)가 '문항 검토 → 최종 완성'에 해당한다.
