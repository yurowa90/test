# 물리학 — 문항 제작의 실제

**출처**: 경기도교육청 (2024). 『2024 평가문항 제작 방법(물리학)』 Ⅲ장 pp.59–107. 내용 체계표는 2015 개정 교육과정 기준이므로 이 앱은 성취기준 코드·문구를 2022 개정 데이터베이스(science_standards.json)에서 가져온다. 아래는 문항 설계에 쓰는 **패턴**이다.

## 행동 영역별 예시 문항의 구조 (pp.62–67)
- **이해**: 핵반응 A(수소→헬륨), B(우라늄→바륨+크립톤) 설명문 → 〈보기〉 ㄱ. A는 핵융합 반응이다. ㄴ. B에서 우라늄 원자핵의 질량수는 바륨 원자핵의 질량수보다 크다. ㄷ. A, B에서 방출되는 에너지는 질량 결손에 의한 것이다. (① ㄱ ② ㄷ ③ ㄱ, ㄴ ④ ㄴ, ㄷ ⑤ ㄱ, ㄴ, ㄷ) — 개념 구분·설명.
- **적용**: 전자기파의 파장 분류 (가) + 전자기파 P, Q로 얻은 영상 (나) → "(가)의 전자기파 A, B, C 중 P와 Q로 옳은 것은?" 짝 선택 정답형 — 실생활 활용.
- **문제 인식 및 가설 설정**: 줄의 실험 장치 A, B(추의 낙하 거리·질량이 다르고 물의 질량은 같음) → 역학적 에너지 변화량, 물이 얻은 열량, 온도 변화 비교 — 실험 장치의 기본 가정 인식.
- **탐구 설계 및 수행**: 소리의 간섭 실험([실험 과정] (가)(나)(다) + [실험 결과]) → 위상, 상쇄·보강 간섭 지점, 위상을 반대로 하면? — 변인(위상·경로차) 이해.
- **자료 분석 및 해석**: 원형 도선 P + 직선 도선 Q, 표(O에서 자기장 세기 vs P의 전류) → 자기장 방향, ㉠(전류 방향), ㉡(크기 비교) — 표의 경향 해석.
- **결론 도출 및 평가**: 점전하 A, B와 전기장 0인 지점·방향 조건 → "A와 B 주위의 전기력선을 나타낸 것으로 가장 적절한 것은?" 그림 선택 최선답형 — 정량 결과를 종합해 전기력선으로 검증.

## 제작 절차 예시 (pp.68–72)
[12물리Ⅰ02-02] 에너지 준위·스펙트럼 → 평가 요소 '불연속적 에너지 준위와 전이 시 에너지 흡수·방출' → 자료: 양자수 n에 따른 에너지 준위 일부 + 전이 A, B, C → 초안 〈보기〉 "ㄱ. A에서 방출되는 빛의 파장은 B에서보다 길다. ㄴ. B에서 방출되는 광자 1개의 에너지는 …이다. ㄷ. C에서 방출되는 빛의 진동수는 …이다." → 컨설팅: 에너지 준위 간격 오류, 문두에 '빛 방출' 없음, 비교 대상 불명확, C의 출발 준위 부재 → 최종: "ㄱ. 방출되는 빛의 파장은 A에서가 B에서보다 길다." 등으로 수정.

## 그림·그래프 작성 유의 (pp.73–75)
발문 진술과 일치, 풀이에 필요한 것만 부각, 사진은 실제와 유사하게, **발문 시점은 실선·이전/이후는 점선**, 필수이지만 풀이에 직접 안 쓰는 표시(직각 표시)는 작게, 상황 설명용 짧은 표현 허용, 그림 문자와 발문 문자 일치, 한 축 안에서 스케일 일치, 보조선은 축과 만나게, 틱으로 값 위치 명확화.

## 문항 수정 사례 15건 — 문제점 → 수정 방향 (pp.76–107)
1. **문제 상황 명확화**(등가속도, 적용): 시간차가 나는 두 물체의 위치를 음영으로 표시 → (가)/(나) 두 그림으로 시점 분리, 실선·점선, 'B가 q를 통과하는 순간 A의 위치 r' 명시.
2. **과학적 오류 방지**(전자기 유도): 자석+코일+나침반 상황은 자석 자기장까지 고려하면 성립 불가 → 교과서 탐구(금속 고리 중심축을 지나는 자석, p·q 통과 시 유도 전류 세기 비교)로 교체.
3. **평가 요소에 맞는 자료**(열역학): (가)→(나), (가)→(다) 두 과정을 병렬 제시하면 초기 상태가 불명확 → 단열 과정 후 등적 과정을 **순차**로 제시, P-V 그래프 변환도 가능.
4. **부족한 단서 보완(1)**(돌림힘): p에 작용하는 힘의 정체·회전 방향 단서 부족 → (가) 평형 상태, (나) 힘 제거 후 회전 순간을 그림으로 제시, 무게중심 후보 q, r.
5. **부족한 단서 보완(2)**(일-운동 에너지): F1, F2가 기호인지 크기인지 불명확, 그래프 음(−) 의미 불명 → 일정한 힘 F + 가속도-시간 그래프, 질량 2 kg, "0초부터 3초까지 F가 물체에 한 일은?" 정답형(18 J~42 J), 다양한 풀이 경로 허용.
6. **기출 유사성 회피**(단진자): 길이·질량 변화에 따른 10회 왕복 시간 표가 기출과 유사 → 운동 분석 장치로 왕복 시간과 **속력 최댓값**을 측정하는 실험으로 재설계, 공식 암기 없이 자료 분석으로 풀리게.
7. **학문적 오류 방지**(전류의 자기장): Q의 전류가 연속 증가하면 P에 유도 전류 → Q의 전류를 일정하게 둔 **실험 Ⅰ·Ⅱ 표**로 제시, 단서 조항 남용 회피.
8. **자료 가독성(1)**(역학적 에너지·용수철): 원래 길이 미제시, 같은 길이를 지나는 순간이 두 번 → 원래 길이 L0 명시, (가)(나)(다) 순차 상태 제시.
9. **자료 가독성(2)**(전기장): 표의 '방향 없음' 표현 어색 → 표 내용을 간접 발문에 녹이고 그림의 축·틱 정리.
10. **자료 가독성(3)**(전류의 자기장): 세 도선의 자기장 방향을 문두에 넣으면 가독성 저하 → **표**(도선별 자기장 세기·방향 ㉠, ㉡)로 제시.
11. **난도 조정(1)**(힘의 합성): 격자 눈금·각 미제시, 새로운 힘 F3 추가는 성취기준 대비 과난도 → 두 힘이 이루는 각을 주고 알짜힘 크기만 묻기.
12. **난도 조정(2)**(포물선): 두 물체의 속력비를 구하는 과정이 식 변환 능력만 요구 → 물체 하나의 최고점 높이를 묻는 개념 중심 문항으로.
13. **정답형 → 합답형**(평면 등가속도): 정답형은 풀이 실마리를 찾기 어려움 → 〈보기〉 ㄱ(걸린 시간 비교) ㄴ(속도 성분 비교) ㄷ(속력 값)로 **논리 순서를 밟아 풀게** 해 난도 하향, [3점].
14. **단순 반복 계산 회피**(등속 원운동): 두 물체의 물리량 비교 반복 계산 → 실로 연결된 A·B 상황에서 A의 질량을 묻는 개념 이해 문항으로, 발문 물리량은 그림에 모두 표시.
15. **교육과정 위배 방지**(뉴턴 3법칙): 부력이 필요한 상황 → 플라스틱 관 속 두 자석의 힘 평형·작용 반작용 상황으로 교체.

## 물리학 문항 설계 규칙 요약
- 상황은 '그림과 같이 …' 간접 발문으로 시작하고, 시점·위치·기준선·방향(+x)을 문장으로 규정한다.
- 단서 조항은 "(단, 물체의 크기와 모든 마찰, 공기 저항은 무시한다.)", "(단, 중력 가속도는 g이다.)"처럼 필요한 것만.
- 비교 명제는 "~는 A에서가 B에서보다 크다." 형식으로 비교 대상과 방향을 고정한다.
- 정량 명제의 값(예: 18 J)은 교사가 검산할 수 있게 해설에 계산 경로를 적는다.
