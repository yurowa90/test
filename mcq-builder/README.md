# 학력평가형 문항 설계·성찰 도우미

교사가 문항 구조와 출제 근거를 이해하고, 직접 수정한 이유를 다음 문항에 적용하도록 돕는 도구입니다. 논술형 자매 앱과 유사한 회청색 작업대·미색 미리보기·단계 탐색을 사용합니다.

## 교사 성장 지원

- 입력·평가 요소·명제 선택을 제출 전에도 저장합니다. 입력과 분석 미리보기는 같은 상태를 사용합니다.
- 자료·명제를 직접 편집하거나 명제를 새로 작성할 수 있습니다. 자료 수정은 모든 명제 확인을, 명제 수정은 해당 명제 확인을 해제합니다. 최종 해설과 승인은 변경 후 무효화됩니다.
- ‘내가 먼저 판단하기’에서는 후보를 진위로 나누지 않고, 교사의 판단과 근거 입력 후 최초 판정과 비교합니다. 일치 여부를 자동 채점하지 않습니다.
- 구조 해설은 성취기준·평가 요소·학생 응답 증거·명제별 자료 연결과 행동 영역을 보여줍니다. 판단 질문은 보조 안내이며 내용 타당성의 자동 검증이 아닙니다.
- 성장 노트는 발견한 문제·바꾼 이유·다음 출제 적용점을 기록합니다. 생성 전·최초 생성본·수동 보관·새 문항 전·복원 전 버전을 보존하고 현재 작업과 비교합니다. 복원하면 최종 승인은 초기화됩니다.
- 자료 출처에 원문 위치·연구 조건·변환 내용·해석 한계를 기록합니다. PubMed·Crossref·OpenStax로 이동하는 검색 안내를 제공합니다. 검색 결과나 원문을 자동 수집·검증하지 않습니다.
- API 키 없이 합성 밀도 자료로 판단·편집·저장·복원을 체험할 수 있습니다. 예시 목표는 공식 성취기준이 아니며 예시 판정은 AI 실호출 결과가 아닙니다.

저장은 이 브라우저에 한정됩니다. v2 초안을 v3 작업 구조로 읽으며 기존 v2 저장 키는 유지합니다. 저장 실패를 화면에 알리고 성찰 Markdown과 전체 JSON 백업을 제공합니다. JSON 가져오기 UI와 서버 동기화는 아직 없습니다. 버전은 자동 삭제하지 않으므로 장기 사용 시 저장 용량을 확인하세요.

전국연합학력평가형 **과학탐구 선다형 문항**(합답형 ㄱㄴㄷ·정답형·부정형)을 만드는 웹앱입니다. 자매 앱인 [GRASPS 설계 도우미](../README.md)(논술·수행과제)의 구조 — CSS 테마, 성취기준 데이터베이스, BYOK Gemini 클라이언트, 교사가 검토·확정하는 2단계 생성 파이프라인 — 를 그대로 가져와 선다형 문항 제작에 맞게 다시 짰습니다.

> 성취기준 → 문항 직행은 "무엇을 평가하는 문항인가"가 비어 있는 문항을 만듭니다. 경기도교육청 『2024 평가문항 제작 방법』은 **교육과정 분석 → 평가 요소 선정 → 문제 장면 설정 → 문항 초안 → 검토 → 완성**의 절차를 요구합니다(p.52). 이 앱은 앞 세 단계를 교사가 확정하는 관문으로 두고, 문항 초안의 기계적인 부분(발문 분기·선택지 배열·복수 정답 차단·난이도 추천)은 규칙으로 처리합니다.

## 파이프라인 (4단계 위저드, 3회 생성)

1. **입력**: 2022 개정 과학과 공식 성취기준 473개(초·중·고 22과목)에서 학교급→과목→영역→성취기준으로 고릅니다(직접 입력도 가능). 문항 옵션과 함께 논문·전공서적·공공데이터의 서지정보, DOI·URL·ISBN·쪽수, 이용 조건, 교사가 원문과 대조한 수치·표·그림 구조를 입력합니다. 출처를 쓰지 않을 때는 교육용 합성 자료임을 결과에 명시합니다.
2. **Pass 1 — 교육과정 분석**: 성취기준 → 필수 학습 요소 · **평가 요소 1개** · 평가 목표 · 행동 영역 · 문제 장면 후보 2~3개(자료 형태가 서로 다름). 교사가 인라인으로 고치고 장면 하나를 고르는 **필수 관문**.
3. **Pass 2a — 자료 + 명제 풀**: 확정된 장면을 구현한 자료(간접 발문·본문·그림 제작 지시·단서 조항) + **참 명제 7개 · 매력적 오답 7개**. 각 명제에 **성취수준 라벨(판별점 기준 A~E)**, 행동 영역, 해설(거짓은 오개념 교정)이 붙습니다. 교사가 ㄱ, ㄴ, ㄷ(정답형·부정형은 ①~⑤)를 고르면 앱이 즉시 조립합니다:
   - 발문 분기: 선택지 항목 수가 같으면 "옳은 것만을 〈보기〉에서 고른 것은?", 다르면 "…있는 대로 고른 것은?"(지침 p.32)
   - 표준 5지 배열 선택(3항 7종, 4항 4종) + 배열 바꾸기, 복수 정답 위험·정답 ① 편중·전부 참 경고
    - 난이도 7등급 추천(명제 수준 평균 + 정답 구조 + 자료 복잡도·부정 발문·교과 융합)
   자료와 명제는 조립 단계에서 직접 고칠 수 있습니다. 수정 후 선택 명제의 진위·근거를 다시 확인해야 다음 단계로 진행합니다. 최종 모델 호출에서는 확인한 자료·명제·정답을 잠급니다.
4. **Pass 2b — 해설·사전 점검**: 교사가 확정한 자료·명제·발문·배열·정답은 잠급니다. 모델은 이를 고치지 않고 정답·명제별 해설·종합 풀이, 문항정보표, AI 사전 점검만 만듭니다. 교사가 출처·진위·교육과정 범위·학생용 출력 분리를 직접 확인해야 학생용·교사용 결과를 내보낼 수 있습니다.

**시그니처 — 조립이 눈에 보이도록**: 명제마다 붙은 수준(A~E)·행동 영역 표식을 보며 ㄱㄴㄷ를 고르는 순간, 발문·선택지·정답·경고·난이도 등급이 오른쪽 패널에서 바뀝니다. 모델은 이 골격을 바꿀 수 없습니다.

## 스택

- Vite + React 19 + TypeScript, Tailwind CSS v4 (자매 앱과 동일한 `index.css` 테마)
- 백엔드 없음 — **BYOK** Gemini. API 키와 작업 초안은 브라우저 localStorage(`mcq-builder:` 접두어)에 저장됩니다. 생성 요청 시 API 키와 입력 내용은 브라우저에서 Google Gemini API로 직접 전송됩니다.
- Gemini `responseSchema`로 JSON 강제 출력.
- Vercel 정적 배포용(`vercel.json`). 같은 저장소에서 두 번째 Vercel 프로젝트를 만들고 **Root Directory를 `mcq-builder`**로 지정하면 됩니다.

## 로컬 실행

### Gemini 연결 점검

- API 설정에서 키 입력 → 모델 목록 조회 → 모델 선택 → JSON 연결 시험 → 저장 순서로 설정합니다. 시험은 짧은 합성 요청이며 토큰 비용·할당량이 소모될 수 있습니다.
- 기본 후보는 `gemini-2.5-flash`입니다. 실제 사용 가능 여부는 키별 모델 조회와 시험으로 확인합니다. 종료된 1.x·2.0 모델은 호출 전에 차단하며, 모델을 몰래 대체하지 않습니다.
- 모델 목록은 `generateContent`와 32,768 이상 출력 한도를 지원하는 텍스트 생성 후보로 제한합니다. 이미지·음성 전용 모델은 제외합니다. 목록에 있다는 사실만으로 JSON 호환성이나 사용량을 보장하지 않습니다.
- 키는 URL 대신 `x-goog-api-key` 헤더로 전송합니다. 취소한 설정은 저장하지 않고, 키 삭제 후 다시 열어도 이전 값이 남지 않습니다. 브라우저 저장·삭제 실패는 화면에 알립니다.
- 요청 제한 시간은 응답 본문 수신까지 120초(목록 조회 15초)입니다. 네트워크·시간 초과는 중복 생성 가능성을 줄이기 위해 자동 재시도하지 않습니다. 500/502/503/504는 한 번 재시도하며, 429는 서버가 알려 준 대기가 10초 이내일 때만 한 번 재시도합니다. 일일 한도·0 할당량은 즉시 안내합니다.
- 응답의 사고 조각을 제외하고 텍스트를 합칩니다. 출력 잘림·차단·빈 응답·잘못된 JSON·필수값 누락·문자열 진위는 결과로 반영하지 않습니다. 세 단계가 사용하는 스키마를 실제 응답에 다시 적용합니다.
- 비교한 논술형 앱: `yurowa90/teacher-essaytest`의 `app.js`. 여러 텍스트 조각 결합과 명시적 출력 길이를 참고했습니다. 그 앱의 2.0 모델 기본값, 키가 포함된 URL, 잘린 JSON 자동 복구는 가져오지 않았습니다.
- 테스트는 외부 요청을 대체하여 정상·실패 응답을 재현합니다. 실제 교사의 키·프로젝트별 한도·학교망에서의 성공을 보장하지는 않습니다.

공식 참고: [모델 조회](https://ai.google.dev/api/models), [생성 API](https://ai.google.dev/api/generate-content), [모델 종료 일정](https://ai.google.dev/gemini-api/docs/deprecations), [오류 해결](https://ai.google.dev/gemini-api/docs/troubleshooting).

```bash
cd mcq-builder
npm install
npm run dev      # http://localhost:5173
npm run build    # tsc 타입체크 + 정적 빌드 → dist/
npm test         # 조립 규칙·수정 후 승인 해제·복원·출력 분리 회귀 테스트
```

## 근거 자료

- **경기도교육청 진로직업교육과 (2024). 『2024 평가문항 제작 방법』 물리학·화학·생명과학·지구과학편 (2024년 11월 발행).** Ⅰ·Ⅱ·Ⅳ장은 4권 공통, Ⅲ장은 과목별. `knowledge/` 각 파일에 인쇄 쪽수를 표기했습니다. 물리학·화학·생명과학편은 Ⅲ장 전체(행동 영역별 예시·제작 절차·자료 유의 사항·평가 문항 수정 사례 15~17건)를 반영했습니다. 지구과학편은 원본 PDF가 Drive 도구의 다운로드 한도를 넘어 Ⅲ장의 앞부분(~p.74, 수정 사례 1건)까지만 반영했습니다. 지구과학편 Ⅲ장 분할본을 올려 주시면 보강할 수 있습니다.
- 사용자 스킬 `sci-mcq-builder`(합답형 작성 규칙, 아이템뱅크 모드, `hapdab_check.py`, `difficulty.py`) — 발문 분기·복수 정답 차단·7등급 난이도 규칙을 `lib/assemble.ts`로 이식했습니다.
- 성취기준·성취수준: 교육부 고시 제2022-33호 별책 9, 교육부·평가원 성취수준 자료 (`public/science_standards.json`).

## 알려진 한계

- 표는 Markdown 표로 렌더링합니다. 그림·그래프는 원문을 복제하지 않고 교사가 입력한 원자료를 바탕으로 **재도식화 제작 지시문**을 냅니다. 실제 시험지에 넣을 최종 도형 파일은 별도 편집이 필요합니다.
- 정량 명제의 값은 모델이 계산하므로 해설의 계산 경로를 반드시 검산하세요. 지침이 말하듯 문항 검토(컨설팅)는 동료 교사의 몫입니다.
- 화면의 7등급은 실제 난도가 아니라 **사전 인지 복잡도 추정치**입니다. 실제 난도는 시행 후 정답률·변별도·선택지 반응률로 판단하고 `assemble.ts`를 재보정해야 합니다.
- 실제 정기시험 원안, 공동출제 비공개 문항, 학생 개인정보는 외부 모델에 입력하지 마세요.
