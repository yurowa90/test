# 완료 기준과 검증 결과

요구사항을 **완료 기준**으로 바꾸고, 실제 파일로 확인한 결과입니다. 초점은 “다양한 형태·형식의 문항을 모아 **일관되고 편집 가능한** 원안지로 취합”하는 것입니다. (검증일 2026-09-29, 커밋 기준 `claude/exam-question-template-app-3lmz0r`)

다시 확인하는 법
- 단위 테스트: `npm test` (합성 픽스처 38건)
- 실제 파일 취합: `npx tsx scripts/e2e.ts <양식.hwp> <출제…> --out out/x` → 문항 수·쪽수·재열기 검증·검수 목록
- 취합 일관성: `npx tsx scripts/check-merged.ts out/x/merged.hwpx` → 글꼴·크기 분포, 그림·표·수식 수, 구조 검증
- 사진 인식 점검: `npx tsx scripts/ocr-try.ts 사진.png --debug` → 찾은 선·동그라미·그림·글자 위치를 겹친 그림

PDF·사진 상자의 내어쓰기는 한글 의미로 고침(첫 줄 0, 둘째 줄부터 내어쓰기 폭) | ✅ 단위 테스트 3건(틀 읽기·다시 짜기·검수). 실파일: 학교 양식 + A.hwp + PDF + 사진에서 상자 44개가 모두 양식 4×5 격자, ㄱ. 시작 위치가 양식과 같음(아래 ‘사람이 확인할 것’의 한글 확인 필요) |
| 문항 번호는 양식의 방식으로 1번부터 이어 붙는다(개요 번호·문단 번호·‘1.’ 글자) | 학교 양식(개요 번호), 학평 양식(개요 번호 + 번호 뒤 한 칸), 글자 번호 양식(픽스처) | ✅ 세 방식 모두 테스트·실파일 통과 |

| 배점·정답·번호 중복이 한눈에 드러난다 | 검수 항목 | ✅ 파일별로 같은 번호가 있으면 ‘번호 중복’, 배점 합계, 정답 분포·연속 |

## 7. 타이포그래피(줄바꿈·고아 줄)

| 완료 기준 | 결과 |
|---|---|
| 단어(어절) 안에서 줄이 끊기지 않는다 | ✅ 결과의 모든 문단 모양에 `breakNonLatinWord=KEEP_WORD`·`breakLatinWord=KEEP_WORD`(단위 테스트로 확인) |
| 문단 첫·끝 줄이 쪽·단 끝에 홀로 남지 않는다(외톨이줄 보호) | ✅ `widowOrphan=1` — 한글이 쪽·단을 나눌 때 적용 |
| 마지막 줄에 두세 글자(한 어절)만 남는 문단은 자간을 줄여 앞 줄로 | ✅ rhwp 줄 나눔(`reflowLinesegs`·`getLineStarts`)을 어절 단위로 다시 채워 찾고, −3%·−6% 두 단계 시도, 효과 없으면 되돌림. 변경 로그 ‘자간 트래킹’에 문항·남던 어절 표시. 학교 양식 + A.hwp: 1개 문단(‘것이다.’) −3%, 혼합 취합: 2개 |
| 문항 사이 빈 줄을 항상 3줄로 두지 않고, 단마다 2·4·6문항이 **균등하게** 들어간다(학교 문항지 관례: 단의 첫 문항은 위, 마지막 문항은 아래) | ✅ 옵션 ‘단마다 균등 배치’(기본). 문항 높이를 rhwp 줄 수·개체 크기로 어림해 단을 채우고, 남는 공간을 (문항 수 − 1)로 나눠 고정 높이 빈 문단 하나로 넣음. 단이 바뀌는 문항은 `columnBreak="1"`(한글·미리보기 모두 같은 자리에서 단 전환). 마지막 단은 자연 배치. 학교 양식 + A.hwp: 15개 단(3·1·4·2·2·2·2·1·1·1·2·1·2·2·2문항), 8쪽(고정 배치는 6쪽 — 문항을 단 사이에서 쪼개지 않으므로 쪽수가 늘 수 있음). 첫 쪽 오른쪽 단은 두 단에 걸친 머리 표 아래에서 시작하도록 용량을 보정(미리보기 엔진은 이 단을 머리 표 위에서 시작해 보여 주지만, 한글은 아래에서 시작). 학평 양식 + B/C: 6개 단 3쪽, 미리보기·재열기 쪽수 일치. 변경 로그 ‘문항 배치’ |

한계: 줄 나눔 어림은 미리보기 엔진의 글꼴 폭 기준이라 한글(신명 중명조)과 한두 글자 차이가 날 수 있습니다. 그래서 확실한 경우(마지막 줄 3자 이하)에만, 작은 폭(−3~−6%)으로만 손댑니다. 최종 줄 나눔은 한글에서 확인하세요(한글의 ‘최소 공백’은 양식 값을 그대로 씁니다). 균등 배치도 같은 어림에 기대므로 단마다 1.5줄의 여유를 남깁니다. 한글에서 한 문항이 어림보다 길어져 단을 넘치면 그 단만 간격이 줄고 다음 단은 단 나누기 덕분에 그대로입니다. 단이 하나뿐인 양식이나 문항이 1개뿐이면 적용하지 않습니다.

## 아직 사람이 확인해야 하는 것

1. **한글에서 최종 확인**: 미리보기(rhwp)는 어울림 그림·표로 시작하는 문항의 번호를 그리지 않거나, 두 단에 걸친 머리 표 아래 오른쪽 단이 표와 겹쳐 보일 수 있습니다. 결과 HWP에는 번호·위치가 들어 있습니다. 이 컨테이너에는 한글이 없어 한글에서의 렌더링은 확인하지 못했습니다.
2. **배포 사이트에서 사진 업로드 1회**: 이 작업 환경은 외부 사이트 접속이 막혀 있어 배포 주소의 동작은 같은 빌드를 로컬 서버로 확인했습니다. 실제 주소에서 사진 한 장을 올려 언어 자료(`/vendor/ocr/lang/kor.traineddata.gz`)가 내려받히는지 한 번 확인해 주세요.
3. **OCR 결과의 빨간 글자**: 원본과 대조해 고친 뒤 검정으로 바꿉니다(내용을 추측해 채우지 않습니다).
