# 완료 기준과 검증 결과

요구사항을 **완료 기준**으로 바꾸고, 실제 파일로 확인한 결과입니다. 초점은 “다양한 형태·형식의 문항을 모아 **일관되고 편집 가능한** 원안지로 취합”하는 것입니다. (검증일 2026-09-29, 교사 사용성 개선 2026-10-06 추가, 커밋 기준 `claude/exam-question-template-app-3lmz0r`)

다시 확인하는 법
- 단위 테스트: `npm test` (합성 픽스처 49건)
- 실제 파일 취합: `npx tsx scripts/e2e.ts <양식.hwp> <출제…> --out out/x` → 문항 수·쪽수·재열기 검증·검수 목록
- 취합 일관성: `npx tsx scripts/check-merged.ts out/x/merged.hwpx` → 글꼴·크기 분포, 그림·표·수식 수, 구조 검증
- 사진 인식 점검: `npx tsx scripts/ocr-try.ts 사진.png --debug` → 찾은 선·동그라미·그림·글자 위치를 겹친 그림

| 정답을 한꺼번에 넣는다 | ‘정답 한꺼번에 입력’: `3 1 2 5 4…`, `①②③`, `1번 3, 2번 1` 꼴 | ✅ PDF 20문항 한 번에, 1~5 밖 숫자는 알려 주고 넣지 않음. 표에서 정답 칸에 커서를 두고 1~5 키로도 지정 |
| 배점이 없는 문항에 교사가 배점을 넣는다 | 3단계 배점 칸 → 발문의 [x점]을 바꾸거나 물음표 뒤에 넣음 | ✅ 변경 로그 ‘배점’, 검수 참고 ‘배점 지정’, 배점 합계에 반영. 단위 테스트 |
| 기호 불일치를 교사가 한 번에 고친다 | 검수 항목의 ‘양식 기호로 바꾸기’, 같은 규칙 묶음의 ‘모두 바꾸기’ | ✅ 물결표·가운뎃점·괄호·〈보기〉 표기만, 되돌리기 가능. 단위 테스트 |
| 사진 문항의 글자를 원본과 대조해 고친다 | 3단계 문항 펼치기 → 원본 사진(확대) + 문단별 ‘고치기’ | ✅ 고친 문단은 검정 글자·줄 배치 캐시 제거, ‘고침’ 표시, 되돌리기로 원래 글. 단위 테스트 |
| 번호로 바로 옮긴다 | 결과 번호를 눌러 새 번호 입력 | ✅ 27번 → 1번 이동 확인 |
| 학생 배부용 파일을 따로 받는다 | ‘학생 배부용 .hwp’: 선택형 문항의 정답 음영을 지운 사본 | ✅ 교사용과 별도 파일, 원본 결과는 그대로. 단위 테스트 |
| 미리보기 첫 쪽이 한글과 같게 보인다 | 미리보기용 사본에만 오른쪽 단 앞 고정 높이 빈 문단(단 나누기) | ✅ 혼합 취합 17쪽 = 17쪽(쪽수 변화 없음), 첫 쪽 오른쪽 단이 머리 표 아래에서 시작. 문항 → 쪽 대응표로 검수 번호를 누르면 그 쪽으로 이동 |
| 바뀐 내용이 결과에 반영되지 않은 채 내려받지 않는다 | 결과를 만든 뒤 문항·옵션을 바꾸면 띠 표시, 내려받기 단추 잠금 | ✅ ‘바뀐 내용으로 다시 만들기’ 뒤 풀림 |
| 작업을 이어서 한다(서버·브라우저 저장 없이) | ‘작업 저장(.json)’ → 같은 파일을 다시 올리고 ‘불러오기’ | ✅ 순서·뺀 문항·정답·배점·기호 바꿈·글자 고침·옵션·파일 순서 복원(정답 20, 배점 1, 고침 1 확인). 출제 파일 자체는 들어가지 않고 문항 열쇠(파일 이름·파일 안 순번)와 설정, 교사가 고친 문단의 글만 저장(고친 글은 시험 내용이므로 파일 관리 주의). 단위 테스트 |

## 아직 사람이 확인해야 하는 것

1. **한글에서 최종 확인**: 미리보기(rhwp)는 어울림 그림·표로 시작하는 문항의 번호를 그리지 않을 수 있습니다. 첫 쪽 오른쪽 단은 미리보기용 사본에만 빈 칸을 넣어 한글처럼 머리 표 아래에서 시작하게 그리지만(내려받는 파일은 그대로), 이 보정이 맞지 않는 양식에서는 겹쳐 보일 수 있습니다. 결과 HWP에는 번호·위치가 들어 있습니다. 이 컨테이너에는 한글이 없어 한글에서의 렌더링은 확인하지 못했습니다.
2. **배포 사이트에서 사진 업로드 1회**: 이 작업 환경은 외부 사이트 접속이 막혀 있어 배포 주소의 동작은 같은 빌드를 로컬 서버로 확인했습니다. 실제 주소에서 사진 한 장을 올려 언어 자료(`/vendor/ocr/lang/kor.traineddata.gz`)가 내려받히는지 한 번 확인해 주세요.
3. **OCR 결과의 빨간 글자**: 원본과 대조해 고친 뒤 검정으로 바꿉니다(내용을 추측해 채우지 않습니다).
