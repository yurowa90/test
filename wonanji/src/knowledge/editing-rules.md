# 편집 규칙과 근거

원안지 편집기가 따르는 규칙을 근거 문서별로 정리했습니다. **자동**은 앱이 서식을 고치는 규칙, **검수**는 알림만 띄우는 규칙, **판단**은 앱이 다루지 않고 선생님이 확인할 항목입니다.

근거 약칭

- [양식] 학교 원안지 양식의 유의사항(양식 파일 안의 ‘※ 유의사항 ※’ 블록). 앱은 이 문구를 파일에서 직접 읽어 규격으로 씁니다.
- [학교] 학교 「정기시험 문항 제작 및 출제 유의사항」(쪽 번호는 원문 한글 파일 기준)
- [연수] 『2026학년도 전국연합학력평가 평가문항 제작 방법 직무연수(통합과학)』 pp.88–92
- [규격] 한글과컴퓨터 「한글 문서 파일 형식 5.0」 공개 문서

## 1. 서식(자동)

| 규칙 | 적용 | 근거 |
|---|---|---|
| 글씨체·글자 크기·줄간격을 양식 예시 문항의 본문 글자 모양으로 통일 | 자동 | [양식] 글씨체·포인트·줄간격 |
| 문항 번호는 양식의 개요 번호(자동 번호), 번호 글자는 양식 번호 모양(12pt 진하게) | 자동 | [양식] 문항번호 12p, 진하게 |
| 논술형 머리 `【문항n-논술형】` 번호 재부여, 12pt 진하게 | 자동 | [양식] 문항번호(논술형 포함) |
| 배점 소수점 한 자리 `[4.0점]` | 자동 | [양식] 배점: 소수점으로 입력 |
| 배점은 물음표 뒤 한 칸 띄워 끝에, 넘치면 다음 줄 오른쪽 | 자동(한 칸·오른쪽 줄) | [학교] p.4 아., p.10 편집 6) / [양식] 2번 발문 참조 |
| 선지가 1~3행이면 탭으로 간격을 일정하게 | 자동(한 줄 5·3·2개) | [양식] 선지 Tab |
| 선지가 2줄을 넘으면 여백 조정(내어쓰기) | 자동 | [양식] 2번 ⑤ 참조 |
| 답안 번호는 문항 번호보다 1칸 들어간 곳에서 시작 | 자동(선지 왼쪽 여백 약 1칸) | [학교] p.10 편집 4) |
| 부정어 밑줄(+진하게) | 자동(옵션) | [양식] 부정어: 밑줄, 진하게 / [학교] p.6 2 “밑줄만 긋고 굵게 표시하지 말 것” ← **두 문서 충돌** |
| 한 문항이 다음 쪽으로 넘어가지 않게 | 자동(다음 문단과 함께) | [학교] p.10 편집 1) |
| 정답 형광펜 보존 | 자동(음영으로 변환) | 원안지 정답 표시 관행, [규격] 영역 태그 |

## 규칙끼리 부딪히는 곳

1. **부정어 표시**: [양식] “밑줄, 진하게” vs [학교] p.6 2 “밑줄만 긋고 ‘굵게’ 표시하지 말 것”, [학교] p.10 편집 5) “밑줄 또는 굵은 글씨, 두 가지를 함께 쓰지 않는다”. 양식은 원안지 편집의 구체 지시이므로 기본값으로 두고, 옵션에서 [학교] 방식을 고를 수 있게 했습니다.
2. **소수점 배점**: [양식]은 “소수점으로 입력(4.0점)”이라는 **표기** 규칙이고, [학교]의 “정수를 원칙”은 **배점값** 규칙입니다. 서로 다른 층위라 둘 다 지킬 수 있습니다(표기는 자동, 값은 참고 알림).
